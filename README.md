# Special Key

A minimalist, single-page web utility hosted via GitHub Pages.

## Overview

A clean, distraction-free interface built with standard HTML, CSS, and vanilla JavaScript. 

- Single-file structure (`index.html`)
- Responsive dark-mode interface
- Built-in clipboard copying functionality
- Hosted directly on GitHub Pages

## Deployment

This project runs statically and requires no build steps or dependencies.

1. Ensure `index.html` is located in the repository root.
2. In the repository settings, go to **Pages**.
3. Under **Branch**, select `main` (or `master`) and save.
4. The live site will deploy automatically.
